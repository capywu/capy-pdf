Capy PDF V7.0 安裝與部署說明
================================

這個壓縮檔有兩個資料夾：
  desktop\  → 做成 Windows 安裝檔（.exe）
  web\      → 放到網站上當網頁版工具


一、做成 Windows 安裝檔（EXE）
--------------------------------
只需要做一次：

1. 安裝 Node.js
   到 https://nodejs.org 下載「LTS」版本，一路按「下一步」安裝即可。

2. 解壓縮這個檔案，打開 desktop 資料夾。

3. 對 build-exe.bat 按兩下。
   - 第一次會下載打包工具，約需 3–10 分鐘（需要網路）。
   - 完成後會自動打開 dist 資料夾，裡面的
     Capy-PDF-Setup-4.0.0.exe 就是安裝檔。

4. 執行安裝檔即可安裝。安裝後會有桌面捷徑和開始功能表項目。
   這個安裝檔也可以複製到其他電腦安裝，那些電腦不需要 Node.js。

想先試跑、不打包：對 run-test.bat 按兩下。

桌面版的額外功能：
  - 在 PDF 上按右鍵 →「開啟檔案」→ 選 Capy PDF 即可直接開啟
    （也可以設為 PDF 的預設程式）
  - 程式已開著時再開 PDF，會在同一個視窗開新分頁
  - 匯出時會跳出「另存新檔」視窗，可選擇存放位置
  - 有未匯出的標註時，關閉視窗前會提醒
  - 完全離線運作，檔案不會上傳到任何地方

注意：
  - 安裝檔沒有數位簽章，第一次執行時 Windows 可能顯示
    「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」即可。
  - 打包失敗時，把黑色視窗中的錯誤訊息貼給 Claude。


二、做成網頁版工具
--------------------------------
web 資料夾是完整的網站，可直接放到任何靜態網站空間，例如：
  - GitHub Pages（免費）：建立 repository，上傳 web 裡的所有檔案，
    在 Settings → Pages 啟用。
  - Netlify（免費）：把 web 資料夾直接拖到 https://app.netlify.com/drop

網頁版的特點：
  - 必須用 https 網址開啟（上面兩種服務都是 https）。
  - 開過一次後，沒有網路也能用（離線快取）。
  - 在 Edge / Chrome 網址列右側點「安裝」圖示，
    就能像一般軟體一樣有獨立視窗和桌面捷徑，
    安裝後還可以把 PDF 用它開啟。
  - 所有 PDF 都在使用者自己的瀏覽器裡處理，不會上傳到伺服器。

更新程式：之後如果功能有修改，只要用新的 index.html
替換 desktop\app\index.html（再執行一次 build-exe.bat），
或替換 web\index.html 並把 sw.js 第一行的 inkdesk-v1 改成 inkdesk-v2 即可。


V4.0 補充：
- OCR 文字辨識第一次使用需要連上網路，會自動下載辨識引擎與語言資料（之後會快取）。
- 桌面版的「儲存」會直接覆蓋原本開啟的 PDF（覆蓋前會提醒），「另存新檔」會跳出 Windows 存檔視窗。

【V4.0 追加功能】
‧修正帶：右側「模式」可選「沿文字自動遮蓋」，像刪除線一樣沿文字拖曳即可自動貼齊遮蓋。
‧頂點編輯：選取單一圖形後拖曳圓點頂點變形；按住 Shift 變成正方形／正圓／正多邊形（直線為 45°）。
‧頂點吸附：拖曳物件或頂點時自動對齊其他圖形頂點，可在選取工具右側關閉（按住 Alt 暫時停用）。
‧右鍵轉盤：齒輪按鈕可自訂內圈 4 個＋外圈 8 個，含複製／貼上／剪下／刪除。
‧全螢幕狀態列：圖釘按鈕可鎖定不隱藏。
‧圖形庫（B）：選取圖形後按「存入圖形庫」，可分類管理、右鍵改名／改分類／刪除。
‧群組：Ctrl+G／Ctrl+Shift+G。對齊與均分：複選後於右側操作，基準可選選取範圍／主要物件／點選的頂點。

【V5.0 新增】
‧圖形旋轉：選取圖形後拖曳上方圓形把手自由旋轉，按住 Shift 以 45° 為單位；右側可直接輸入角度。
‧上方新增「圖形修改」；點任何上方分類，下方都會出現該分類的次工具列（右鍵工具可加入常用工具列、連點兩下開快速設定）。
‧矩形／遮蓋／圖片／印章／便利貼有 8 個控制點（4 角＋4 邊中點），Shift 變正方形後仍保留 8 點；旋轉後照樣可拖曳變形。
‧右鍵轉盤：可加入所有工具與功能（含旋轉、群組、對齊等）；新增「更多…」清單；編輯視窗中按住項目約 1 秒可直接拖曳排序，也能在轉盤與「更多…」之間拖移。

【V5.0 追加：編輯 PDF 原文字與 Word 匯出】
‧編輯 PDF 文字（審閱 → 編輯 PDF 文字，快捷鍵 D）：點原文字＝編輯整行，拖曳＝編輯範圍；清空內容＝刪除。會自動取用原文字的字級、顏色、字型（黑體／明體）。
‧「選取文字」選字後也有「編輯／刪除」按鈕，或直接按 Delete 刪除。
‧匯出（左側匯出鈕或 Ctrl+E）：PDF 或 Word（.docx）。
  - PDF 可勾選「真正移除原文字」：有編輯過原文字的頁面會轉成高解析影像，原文字徹底消失。
  - Word 可選：可編輯文字／版面影像／影像＋可編輯文字。
‧EXE 版需重新打包（main.js 已更新，另存視窗支援 .docx）。
‧重新排版（編輯 PDF 文字 → 右側「排版」）：
  - 逐行覆蓋：只換掉那一行。
  - 段落內自動換行（預設）：點一下選整段，修改後在原段落寬度內自動換行。
  - 段落內換行＋自動縮字：超出原區塊時自動縮小字級。
  - 段落重排＋下方文字跟著移動：下方同一欄的文字會一起往下推或往上收（圖片與線條不會移動）。
  - 換行文字框右側有控制點，可拖曳改變寬度重新換行。
‧搜尋（上方工具列右側，Ctrl+F）：所有符合處以黃色標示、目前這筆為橘色；Enter／F3 下一筆，Shift+Enter／Shift+F3 上一筆，Esc 清除。也會搜尋文字方塊、便利貼與修改過的文字，已刪除／遮蓋的原文字不會被找到。
‧尋找並取代（搜尋列的 ⇄ 鈕或 Ctrl+H）：「取代」換目前這筆、「全部取代」一次換完；PDF 原文字依排版設定重排，可 Ctrl+Z 一次復原。
‧獨立工具列：次工具列每組前面的「⋮⋮」可拖到畫面上變成浮動工具列，拖到右側邊緣會吸附；拖回次工具列或連點兩下標頭即可放回。「圖形修改」的按鈕只顯示圖示，滑鼠停留會顯示說明。
‧編輯 PDF 文字新增「智慧排版」（預設）：自動套用原文字的字型、粗細、寬度與底色（例如綠色儲存格），修改後在儲存格／欄位內換行，放不下自動縮小字級，不會蓋到旁邊或下一列。
‧左側常用工具列第二列：第一列的雙欄按鈕可顯示／隱藏第二列；第二列有自己的工具（各最多 20 個），可單獨浮動或吸附在左側；按鈕右鍵可「移到第一／第二列」。
‧修改後的 PDF 文字：會依原文字的筆畫實際高度與寬度自動符合字級、字寬與位置。選取該文字後右側可調字級、字寬、行距、方向微調（Alt+方向鍵＝0.2pt），並有「自動符合原文字」「填滿原寬度」「放不下時自動縮小」；拖曳文字框右下角圓點可直接縮放。
‧狀態列：長按任一按鈕（含分隔線）約半秒即可拖曳調整順序，會自動記住。
‧三分割檢視：狀態列的三欄按鈕，同時顯示同一文件三個不同頁面（各欄可獨立捲動、翻頁與標註）。
‧並排 3 頁／4 頁：狀態列的並排按鈕；連續模式下每列 3 或 4 頁捲動，單頁模式下一次顯示 3／4 頁、翻頁一次跳 3／4 頁。

【V6.0】
‧右側屬性面板標題列新增「隱藏」按鈕：面板收成右側的小標籤，增加顯示空間；點標籤即可再顯示，按住標籤上下拖曳可調整位置（會記住）。
‧關閉程式時會記住所有工具列位置與狀態（常用工具列兩列、屬性面板、獨立工具列、狀態列順序、目前工具、檢視模式等），EXE 版也會記住視窗大小、位置與是否最大化，下次開啟沿用。
‧關閉視窗時若有未儲存的文件，會出現「儲存／不儲存並關閉／取消」；按「儲存」後，有原始 PDF 的文件會再詢問是否覆蓋原檔（可改存新檔），沒有原始檔的會請你選擇位置，全部存好才關閉。

【改名】
‧軟體名稱改為 Capy PDF。安裝新版時會沿用舊版（InkDesk PDF）的設定與工具列位置；安裝檔的 appId 不變，會直接取代舊版。

‧馬賽克（審閱 → 馬賽克，快捷鍵 Z）：可「自行框選範圍」或「沿著文字」；可調格子大小（密度）、方格／柔化模糊、打亂格子（較難還原）。選取已畫的馬賽克可再改設定與範圍。選取文字工具的工具列也有馬賽克按鈕。
‧批改（審閱 → 批改，快捷鍵 F）：選取文字自動畫 X，跨多行會在整個範圍畫一個大 X；畫完可輸入修改後的文字，位置可選右側／上方／下方，字級可自動或指定。X 與備註文字都能用選取工具移動、調整大小與顏色。
‧匯出 PDF 勾選「真正移除…」時，有遮蔽或馬賽克的頁面也會轉為影像，原文字徹底移除。
‧程式圖示改為水豚（Capybara）圖案：程式內 Logo、EXE 圖示／安裝檔／捷徑、網頁版 App 圖示都已更新。
‧右鍵選單改為直列文字選單；最上方「自訂右鍵選單…」可增刪項目、調整順序（按住約 1 秒拖曳），需要先選取的功能會顯示為灰色。
‧文字樣式（文字方塊與編輯 PDF 文字）：右側可選字型（含原 PDF 字型、微軟正黑體、新細明體、標楷體、Arial、Times New Roman 等）、字級、粗體 B／斜體 I／底線 U、靠左／置中／靠右；編輯 PDF 文字時可即時套用。
‧文字方塊底色：右側「底色」可選常用色或自訂顏色。
‧文字框大小：選取後拖曳圓點調整——右側＝寬度（自動換行）、下方＝高度、右下角＝寬高；按住 Shift 拖右下角＝等比例縮放字級。
‧狀態列新增「並排雙頁」：連續模式每列兩頁；單頁模式一次顯示兩頁、翻頁一次跳兩頁。
‧修正：掃描式圖檔（傳真壓縮 CCITT／JBIG2、JPEG 2000）以及使用未內嵌中日韓字型的 PDF 顯示空白的問題（已內建所需解碼元件，可離線使用）。
